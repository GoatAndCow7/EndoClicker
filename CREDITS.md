# Crédits des textures

## Pixel Perfection CE (Community Edition)

Les textures d'items et de blocs utilisées dans EndoClicker (`client/public/textures/`)
proviennent du pack de textures **Pixel Perfection CE** :

- **Auteur original** : Hugh « XSSheep » Rutland — Pixel Perfection
- **Édition communautaire** : https://github.com/Athemis/PixelPerfectionCE
- **Licence** : [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.fr)
  (Paternité — Partage dans les Mêmes Conditions)

Conformément à la licence :
- Les textures incluses sont créditées ci-dessus (paternité).
- Toute réutilisation de ces textures doit conserver cette attribution et la
  même licence CC BY-SA 4.0 (partage dans les mêmes conditions).
- Le texte complet de la licence est disponible dans
  `client/public/textures/LICENSE-PixelPerfectionCE.md`.

## Têtes des joueurs

Les têtes affichées dans l'onglet Équipe sont générées via
[mc-heads.net](https://mc-heads.net) à partir des pseudos Minecraft réels des
membres du staff.
